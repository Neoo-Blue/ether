large-fixture timeouts and DB-time growth in several surfaces. An exclusive
retry was interrupted during critical memory pressure; a later retry was
stopped under the coordinator's directive that workers not run full suites.
The coordinator owns the final performance and full-suite gates.
Production's read-only ring included metadata at 568 statements / 51 writes
and postplay at 1,028 statements / 159 writes. Four matching numeric paths
were extracted into private scratch and replayed offline; matching timestamps
and logged durations identify the corresponding requests. These runs yielded
zero writes, so the production write amplification has not been reproduced.
An offline local-provider check of repeated recommendation and collection
calls preserved title data and reduced 206 statements / 194 writes to 103 / 97;
a 24-title reload comparison preserved order and data while reducing 72
statements to 3. Those temporary checks were removed under the owner directive.
The remaining cold taste build still aggregates a viewer's 30-day impression
history, so a hard library-size-independent work bound has not been established.
